# 📄 RAG-Based Document Q&A System

## Overview
The RAG-Based Document Q&A System is an AI-powered application that allows users to upload documents (such as PDF files) and ask questions in natural language. The system retrieves relevant information from the uploaded documents and generates accurate answers using Retrieval-Augmented Generation (RAG).

## Features
- Upload PDF and document files
- Ask questions in natural language
- Semantic document search
- AI-generated answers based on document content
- Fast and accurate information retrieval

## Technologies Used
- Python
- LangChain
- FAISS
- OpenAI / LLM
- Streamlit (if used)
- PyPDF
- Sentence Transformers

## How to Run

1. Clone the repository
```
git clone https://github.com/your-username/RAG-Document-QA-System.git
```

2. Install dependencies
```
pip install -r requirements.txt
```

3. Run the application
```
python app.py
```
